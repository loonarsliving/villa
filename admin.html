Kredensial Cloudbeds
Dikonfigurasi lewat Environment Variables di Vercel, bukan di panel ini
API key Cloudbeds tersimpan sebagai Environment Variable di project Vercel (living.haluoleo.id), supaya tidak lewat form web. Set variabel berikut di Vercel → Project Settings → Environment Variables:
VariabelKeterangan
CLOUDBEDS_API_KEYAPI key dari akun Cloudbeds Anda
CLOUDBEDS_PROPERTY_IDProperty ID Cloudbeds
CLOUDBEDS_WEBHOOK_SECRETSecret bebas untuk validasi webhook masuk
SUPABASE_URLhttps://svcmybsziaelwwdrnzcv.supabase.co
SUPABASE_SERVICE_ROLE_KEYDari Supabase Dashboard → Project Settings → API
Setelah itu, daftarkan URL webhook berikut di dashboard Cloudbeds untuk event reservasi baru:
https://living.haluoleo.id/api/webhooks/cloudbeds?secret=<isi sama dengan CLOUDBEDS_WEBHOOK_SECRET>
Lalu petakan setiap tipe kamar Cloudbeds ke unit villa di bawah ini (data mapping ini bukan secret, tetap dikelola di sini seperti biasa).

Kredensial WhaCenter
Dikonfigurasi lewat Environment Variables di Vercel, bukan di panel ini
API key WhaCenter tersimpan sebagai Environment Variable di project Vercel (living.haluoleo.id). Set variabel berikut di Vercel → Project Settings → Environment Variables:
VariabelKeterangan
WHACENTER_API_KEYAPI key dari akun WhaCenter Anda
WHACENTER_DEVICE_IDDevice ID WhaCenter yang terhubung ke nomor WA
WHACENTER_BASE_URLOpsional, default https://api.whacenter.com/api/send
INTERNAL_BRIDGE_SECRETfa0acfa7926b88c5ad6e268b15a0fd3121c4a06da889b1c9
INTERNAL_BRIDGE_SECRET harus persis sama dengan nilai di atas — ini kunci rahasia supaya hanya sistem villa (bukan sembarang orang) yang bisa memicu pengiriman WA lewat Vercel. Setelah semua variabel di-set dan project di-redeploy, konfirmasi booking & PIN kamar saat check-in akan terkirim otomatis.
